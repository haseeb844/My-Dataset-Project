 My Sports League Project
Sports League 

The main reason for making this dataset is to collect and organize information about sports leagues from all over the world in one easy place. Instead of having to look at many different websites to find sports news and financial facts, this dataset puts everything into a simple chart. It keeps track of four important things for each league: the type of sport, the country where it is played, the total money the league makes, and the average amount of money a player earns each year. Having all this information set up the same way makes it very easy to compare different sports and countries fairly, without getting confused by mismatched details.The Sports League Database website takes this big list of numbers and turns it into a simple, helpful website that anyone can use. Big blocks of raw numbers are usually very hard to read and understand, so the website fixes this by giving users tools to find information quickly. People using the website can type in words to search for a specific sport or country, sort the lists from highest to lowest to see who makes the most money, and put different leagues next to each other to compare them directly. In the end, the website helps fans, students, or reporters spot big trends, like finding out which sport has the most leagues worldwide or seeing if leagues that make more money always pay their players higher salaries.
